# PageVault

PageVault 是一个轻量的本地收藏管理网页，本用于独立博客文章收藏，后拓展为书签管理（亦可用于博客收藏）。基于原生 HTML、CSS 及 JavaScript，开箱即用。

Powered by Exsshly with CodeX.

## 快速开始

1. 将 `index.html`、`styles.css` 和 `app.js` 置于同一目录。
2. 使用现代浏览器打开 `index.html`。页面默认进入首页 **All**。
3. 通过侧栏 All 后的“➕”添加站点，或使用 稍后再看 后的“➕”快速添加稍后再看。
4. 通过侧栏“备份与还原”定期导出 JSON 备份。

项目文件：

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构、按钮和对话框 |
| `styles.css` | 布局、主题、响应式样式 |
| `app.js` | 数据模型和所有交互逻辑 |
| `README.md` | 使用和数据说明 |

## 数据与备份

### 保存位置

收藏数据保存在当前浏览器的 `localStorage` 中，键名为 `blog-vault-data`。界面还会保存主题、视图和侧栏折叠偏好。数据不会自动写入项目文件，也不会在浏览器或设备之间同步。浏览器清理站点数据、使用其他浏览器或更换设备，都可能使当前数据不可见或丢失。

侧栏底部状态点表示：

- **红色**：当前是浏览器本地数据。
- **绿色**：数据从备份导入，导入后尚未修改。
- **黄色**：导入后的数据已发生修改，需要注意保存或导出。

有备份时间的文件会显示备份时间。

### 导出和还原

打开侧栏 **备份与还原**：

- 顶部显示当前站点及子页数量，包含 稍后再看，回收站中不计数。
- 点击 **导出备份**保存 JSON 文件，导出时使用本地时间。
- 选择备份文件后确认，即可还原。**还原会提示覆盖或合并**，根据实际需求选择。
- 备份保存目录、站点、子页、标签和已删除的子页等内容。

### 清空数据

备份窗口中的 **清空数据**会删除 PageVault 在当前浏览器中保存的收藏和界面偏好，无法撤销。操作前如必要请先导出备份；确认后清空数据。

## 侧栏与页面

- **All**：展示已收录站点及其子页，不包括 稍后再看、回收站和被设置为首页隐藏的目录。支持全部展开、收起。
- **ReadLater（稍后再看）**：暂存稍后再看站点。右键菜单支持编辑、收录或删除。
- **Flitter**：全局搜索与条件筛选页面。首次进入或重置后没有结果；可输入关键词，或用“添加条件”选择目录和标签。目录与标签条件同时生效；多个标签匹配任意一个即可。未选择的条件不限；重新进入页面保留本次筛选条件，刷新后重置。
- **文件夹**：点击目录查看该目录直接包含的站点。侧栏数量包含其子孙目录的站点。
- **回收站**：位于侧栏底部，暂存已删除的站点和单独删除的子页。

## 收藏站点

### 添加与编辑

可从顶部➕、All 后的➕或 稍后再看 后的➕添加：

- All 后的➕默认选择“已收录”；稍后再看 快速添加直接进入 稍后再看。
- 在普通目录页添加时，默认选择当前目录；其他全局入口可选择 稍后再看 或目录。
- 名称可留空，系统按域名中以 `.` 分割后的最长一段生成名称。
- 链接省略 HTTP(S) 协议时自动补 `https://`；缺少末尾 `/` 时自动补全。查询参数或片段前的路径也会补 `/`。
- 可添加备注、标签并选择所属目录。

添加或编辑站点时会检查重复链接，提示后可取消、编辑已有收藏或仍然新增。比较时会忽略 URL 片段、路径末尾斜杠，并按小写比较；保留路径差异。

> 自动补充末尾斜杠可能改变某些带文件名的地址的访问结果，请在收藏后检查链接。通过浏览器书签导入的原始链接在未修改时会保留。

### 查看与管理

点击站点**名称或头像**在新标签页打开；点击链接复制链接。普通目录卡片可打开子页列表；有子页时角标显示数量，超过 99 则显示 `99+`。All 页面收起的站点卡片也显示角标。

卡片可右键编辑、删除，或按名称、收藏时间切换该站点子页的升序／降序。站点卡片可拖到侧栏目录移动；移动站点时其子页一起移动。站点及子页的备注、标签在 All 页直接显示；其他目录页停留约一秒显示提示。

## 收藏子页

在站点子页菜单中点击“收藏子页”，或使用页面上的“收藏子页”按钮。子页可填写标题、链接、备注和标签；标题留空时使用链接末尾路径段并尝试解码。

手动选择站点时，列表以当前分区为范围。输入链接后，程序会按域名自动搜索全部未删除站点（含稍后再看）；匹配到其他分区时显示其目录。当前按域名选择第一个匹配站点，同域名有多个站点时请检查归属。若无匹配站点，可确认创建站点后保存子页。

编辑子页并改变所属站点时，子页会从旧站点移到新站点。；

删除子页后可在回收站恢复到原站点；原站点不存在时，恢复操作会在“无索引”目录中按链接域名查找或创建站点来收纳子页。

## 文件夹和首页显示

点击“文件夹”标题后➕新建目录，可选择上级目录并建立多级目录。“已收录”为系统目录，不可删除。

普通目录的更多菜单或右键菜单支持：

- 新建子目录、重命名、删除目录。
- 置顶／取消置顶：同级置顶目录按置顶时间从新到旧排列；置顶图标内部填充所选颜色。
- 在首页中显示／隐藏：隐藏后，该目录默认不出现在首页；未单独设置的子目录继承上级状态，子目录可单独设置显示状态。
- 按名称或收藏时间排序当前目录内的站点；再次选择同一规则切换方向。
- 选择文件夹颜色。隐藏目录使用虚线标注；隐藏目录中有单独显示的后代时，图标内显示短横线。

“已收录”提供新建和排序等操作，不提供重命名或删除。删除普通目录时，其站点会进入回收站；提示时间内可通过撤销。恢复站点时，可重建保存的原目录结构或选择新位置。

## 搜索、排序和视图

顶部搜索框匹配站点名称、链接、备注，以及子页标题、链接、备注。普通目录页的搜索范围是当前目录直接包含的站点；All 和 Flitter 使用各自的页面范围。筛选结果按站点展示，匹配到子页时显示其所属站点。

顶部排序菜单支持名称和收藏时间升降序，回收站还支持删除时间。当前规则前有勾选标记，重复点击同一项可切换方向。目录的排序保存在目录数据中；All 页排序只用于当前页面，刷新即重置。

支持浅色／深色主题；除 All 页外可切换卡片／列表视图。首次使用主题跟随系统，手动选择后保存在浏览器中。

## 多选与批量管理

在收藏页面点击 **多选**，点击站点卡片选择；浮动工具栏提供：

- **Select all**：选择当前搜索或筛选结果中的全部站点，包括 All 页尚未加载的站点。
- **Open**：批量打开站点；需要注意浏览器可能阻止多个新标签页。
- **Move**：选择目标目录或 稍后再看，移动所选站点及其子页。
- **Tag**：为所选站点批量添加已有标签。
- **Delete**：将站点移入回收站；操作后的提示可短时撤销。

回收站的工具栏提供 Restore、Select all、Move 及 Wipe。回收站支持恢复、移动或彻底删除。移动子页时按链接域名在目标目录中查找或创建站点。

侧栏 **批量管理**提供两栏，可选择两侧目录、交换两册目录，拖动站点卡片移动；展开卡片后，可将子页拖到另一站点。

“文件夹”标题旁的图标进入 **层级管理**。左右两栏均为目录树，默认收起；可展开子目录。拖拽目录卡片拖到其他目录卡片可改变包含关系，拖到目录之间的插入位置可调整顺序。两栏为同一目录树的两个视图；已收录本身不显示为可移动项。置顶目录仍按置顶规则显示。

## 标签

在 **设置管理 → 标签管理**中：

- 点击虚线标签添加，输入后按 Enter 或点击箭头确认。
- 右键标签可原位修改名称；点击红色叉号删除。
- 按住标签拖到另一个标签上可交换顺序。

添加或编辑站点、子页时，可点击已有标签选择，也可通过虚线按钮新建标签。修改或删除标签会同步更新使用该标签的收藏。

## 回收站

删除站点会将站点及其子页一起移入回收站；单独删除的子页也会进入回收站。页面显示删除时间及原目录或原站点。可恢复、移动或彻底删除站点；子页可恢复或彻底删除。清空回收站会永久删除其中站点和子页，且不可撤销。

部分删除和移动操作完成后，顶部提示提供短时“撤销”。已彻底删除的内容（Wipe）无法恢复。

### 无索引目录

“无索引”是与“已收录”平级的黄色系统目录，该目录不可移动或删除；只在包含站点时显示。恢复原站点已不存在的子页时，程序按子页链接的域名创建或复用站点并收纳子页。

## 设置管理中的工具

### 重复收藏检查

**重复收藏检查**。支持全局检查和自定义目录检查，有重复项时进入管理，按站点和子页分别分组。可选择目标合并：站点合并时子页按 URL 去重，备注与标签合并；子页合并时保留所选目标并合并备注和标签。

注意：重复管理中的“删除”是**直接删除，不进入回收站**。删除重复站点时，如没有其他单个重复站点包含它的全部子页，会提示确认。操作前建议先备份。

### 强制整理（测试）

选择一个目录，工具将读取该目录及所有子目录，将可识别域名的站点和子页按域名归类，在与“已收录”平级的新目录中生成整理结果。原收藏保持不变；无法识别域名的链接会跳过并在结果提示中计数。此功能为测试功能，建议操作钱备份并检查结果。

### 从其他浏览器书签导入（测试）

选择 Chrome 或 Edge 导出的书签 HTML。程序会在顶级新建“外部导入”目录，重建导出文件中的目录，把书签作为站点导入；重复 URL 会跳过，非 HTTP(S) 链接会保留原值。导入前会显示数量并请求确认。特殊协议能否打开取决于浏览器和系统。该功能为测试功能，导入后请检查目录和链接。

## 使用说明

- 静态页面应用，不提供账号、自动同步或服务端存储。
- 浏览器的本地存储容量和 `file://` 权限因环境而异；批量打开、剪贴板和特殊协议可能受浏览器限制。
- 更换静态页面目录时保存的存档位置不同，移动静态页面应用时需注意当前路径下打开应用是否存有数据。
- 链接自动匹配基于域名，不区分同域名下不同博客路径；手动确认归属可以避免误判。
- 提供备份与还原，但不自动生成备份；重要数据请定期导出并保存在浏览器之外。
